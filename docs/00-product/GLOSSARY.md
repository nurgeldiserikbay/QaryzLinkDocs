# Glossary

| Термин | Анықтама |
|---|---|
| User | Жүйеге кіретін аккаунт |
| Party | Шартқа қатысатын жеке немесе заңды тұлға |
| Lender | Міндеттемеде қаражат беруші Party рөлі |
| Borrower | Міндеттемеде қаражат алушы Party рөлі |
| LenderOffer | Қарыз берушінің жария немесе жабық жалпы талаптары |
| BorrowerRequest | Қарыз алушының matching үшін жариялаған preference-тері |
| Application | Offer-ге берілген өтінім |
| Proposal | Нақты lender мен borrower арасындағы талаптар ұсынысы |
| Negotiation | Proposal version-дарымен келіссөз |
| Contract | Тараптар арасындағы шарт identity-і |
| ContractVersion | Өзгермейтін нақты шарт нұсқасы |
| SignatureGroup | Бір ContractVersion үшін міндетті қолдар жиыны |
| Funding | Қарыз қаражатын беру процесі |
| FundingConfirmed | Ақша берілгенін сенімді түрде бекітетін оқиға |
| Obligation | Funding-тен кейін орындалуы тиіс қаржылық міндеттеме |
| ScheduleVersion | Белгілі calculation input бойынша жасалған кесте нұсқасы |
| ScheduleItem | Бір төлем мерзімі |
| Payment | Қарызды өтеуге қатысты төлем claim/record |
| LedgerEntry | Балансқа әсер ететін append-only бухгалтерлік оқиға |
| Amendment | Қолданыстағы шартты жаңа version арқылы өзгерту |
| Dispute | Funding, payment, calculation немесе contract бойынша дау |
| Evidence | Фактіні дәлелдеуге тіркелген материал |
| ConsentGrant | Нақты деректі нақты мақсатпен ашуға берілген рұқсат |
| VerifiedClaim | Провайдер растаған жеке атрибут |
| CountryPack | Бір елдің rules, templates, retention және providers конфигурациясы |
| LegalGate | Функцияны production-да қосар алдындағы заңдық рұқсат шарты |
| AssuranceLevel | Жазбаның identity/signature тұрғысынан сенім деңгейі |
| Snapshot | Белгілі уақыттағы өзгермейтін дерек көшірмесі |
| Projection | Source events-тен есептелетін read model |
| Idempotency | Бір сұраныс қайталанса да нәтиженің бір рет қолданылуы |
